## 📌 نبذة عن الداشبورد
لوحة تحكم تفاعلية متكاملة لمتابعة وتحديث نسب الإنجاز الشهرية لكافة مشاريع القطاع الصحي لعام 2026 (الشمال، الوسط، الجنوب).
- تم تضمين كافة المشاريع (105 مشاريع) بدون أي مشاريع قديمة منتهية في 2024 أو 2025.
- مزودة بنظام صلاحيات وتسجيل دخول محمي بكلمات مرور لكل منطقة والإدارة العليا.
- مربوطة بنظام تخزين وتحديث فوري للمعلومات.

## 🚀 طريقة الرفع والربط المباشر مع GitHub Pages (خلال دقيقة واحدة):

1. أنشئ مستودعاً جديداً (New Repository) في حسابك على **GitHub** باسم: `moh-projects-dashboard-2026`.
2. ارفع ملفات هذا المجلد (`index.html`, `سجل_مشاريع_الصحة_2026_حصريا.xlsx`, `projects.json`).
3. ادخل إلى إعدادات المستودع **Settings** -> **Pages**.
4. تحت خانة **Branch**، اختر `main` واضغط **Save**.
5. سيصبح الرابط التفاعلي جاهزاً ويعمل مباشرة أونلاين على الرابط:
   `https://<your-username>.github.io/moh-projects-dashboard-2026/`

## ⚡ خيار الربط السحابي المباشر عبر Google Firebase (Realtime Database):
إذا أردت مزامنة التعديلات عبر الإنترنت لحظياً بين عدة أجهزة مختلفة في نفس الثانية دون الحاجة لتحديث الصفحة:
1. أنشئ مشروعاً مجانياً على [Firebase Console](https://console.firebase.google.com).
2. فعّل **Realtime Database**.
3. انسخ كود الـ Firebase Config وضعه في المكان المخصص داخل `index.html`.
